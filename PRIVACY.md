# ContextLens Privacy Notice

ContextLens captures the visible state of web pages only when the user explicitly selects a target and clicks Capture. Captures are stored locally in Chrome extension storage and can be copied or downloaded by the user.

ContextLens does not use analytics, advertising, accounts, a backend, a database, or remote services. It does not sell or share captured content.

Sensitive input values are redacted by default, including password, hidden, payment, secret, token, SSN, and card-related fields. Users should still review a snapshot before sharing it with an AI coding assistant or another person.

The extension requests access to web pages because semantic capture, same-origin frame inspection, locator generation, and screenshot capture require access to the selected page. Browser-internal pages, native dialogs, cross-origin frame internals, closed shadow roots, and canvas-only content are not captured.
